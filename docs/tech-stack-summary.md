# FitFlow Technology Stack Summary

## Frontend

**React Native + React Native Web**

Provides cross-platform development for iOS, Android and web while
allowing rapid development and reusable components.

## Backend

**Node.js + NestJS**

Provides a structured TypeScript backend for APIs, authentication
checks, business logic and real-time integration.

## AI Service

**Python AI Service + TensorFlow**

Provides AI-powered personalized workout recommendations and supports
advanced machine-learning functionality.

## Computer Vision

**ML Kit**

Used for camera-based food recognition and nutrition tracking.

## Databases

### Firestore
Used for:
- Social feeds
- Challenges
- Real-time updates
- Social activity

### PostgreSQL
Used for:
- Health information
- Workout history
- Nutrition records
- Progress metrics

## Authentication

**Firebase Authentication**

Provides user authentication and integration with the Firebase
ecosystem.

## Cache

**Redis**

Used for frequently accessed information such as dashboards and
leaderboards.

## Analytics

- Firebase Analytics
- Mixpanel

Used to monitor user behaviour, engagement and post-deployment
performance.

## Key Benefits

- Cross-platform development
- Rapid development
- Real-time capabilities
- AI/ML support
- Computer vision
- Scalability
- Security and privacy
- Maintainability
